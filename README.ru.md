# NanoGadgets - Складской отчет

[English](README.md) | Русский

## Что это за проект

NanoGadgets Inventory Report - это небольшое приложение на PHP и React для ведения складского ассортимента и генерации Excel-отчета.

Проект начался как тестовое задание по PHP: нужно было создать `.xlsx` отчет для вымышленной компании NanoGadgets, которая продает высокотехнологичные мелочи вроде умных колец и мини-проекторов. Поверх исходного задания был добавлен полноценный веб-интерфейс, сохранение в SQLite, справочники категорий и товаров, фильтры, сортировка, пагинация и ручное сохранение изменений.

## Из чего состоит проект

```text
.
├── generate_report.php                 # CLI-скрипт генерации XLSX из демо-данных
├── output/
│   └── NanoGadgets_report.xlsx          # Пример сгенерированного отчета
├── data/
│   └── inventory.sqlite                 # Локальная SQLite-база, создается автоматически
├── public/
│   ├── index.html                       # Точка входа браузерного приложения
│   ├── api/
│   │   ├── download-xlsx.php            # Генерация и скачивание XLSX
│   │   └── inventory.php                # JSON API товаров, категорий и справочника товаров
│   └── assets/
│       ├── app.jsx                      # Тонкий слой сборки React-экрана
│       ├── components/                  # React-компоненты интерфейса
│       └── composables/                 # Логика состояния и бизнес-операции

    ├── Data/                            # Начальные демо-товары
    ├── Report/                          # Генерация отчета и нормализация товаров
    ├── Storage/                         # Репозиторий SQLite
    ├── Xlsx/                            # Низкоуровневая сборка XLSX/XML
```

## Требования

- PHP 8.1 или новее.
- PHP-расширения: `pdo_sqlite`, `zip`, `xml`, `mbstring`.
- Браузер с доступом к интернету для CDN-скриптов интерфейса:
  - React 18;
  - ReactDOM 18;
  - Babel Standalone;
  - Tailwind CDN.

Composer и npm устанавливать не нужно.

## Что делать после распаковки архива

1. Распакуйте архив.

2. Откройте терминал в папке проекта:

   ```bash
   cd NanoGadgets
   ```

3. Запустите локальный PHP-сервер:

   ```bash
   php -S 127.0.0.1:8000 -t public
   ```

4. Откройте приложение в браузере:

   ```text
   http://127.0.0.1:8000/
   ```

5. Редактируйте справочники и ассортимент. После изменений подтвердите сохранение через `Сохранить изменения? Да` или откатите через `Нет`.

6. Скачайте Excel-отчет кнопкой `Скачать XLSX`.

Также можно сгенерировать исходный отчет из демо-данных без браузера:

```bash
php generate_report.php
```

Или указать свой путь для файла:

```bash
php generate_report.php output/custom_report.xlsx
```

## Что делает PHP

PHP отвечает за backend и генерацию отчета:

- Отдает JSON API из `public/api`.
- Сохраняет и загружает данные через SQLite.
- Валидирует товары перед генерацией XLSX.
- Собирает Excel-файл вручную как OpenXML `.xlsx` пакет.
- Добавляет оформление, фильтр и условное форматирование.

Основные PHP-части:

- `src/Storage/InventoryRepository.php` создает и обслуживает SQLite-таблицы.
- `src/Report/ProductNormalizer.php` проверяет и нормализует строки товаров.
- `src/Report/InventoryReportGenerator.php` управляет генерацией отчета.
- `src/Report/InventoryWorksheet.php` собирает содержимое листа.
- `src/Xlsx/*` создает ZIP-пакет XLSX и XML-файлы.

## Что делает React

React отвечает за браузерный интерфейс:

- Редактирование ассортимента.
- Справочники категорий и названий товаров.
- Редактирование справочников на месте.
- Сворачивание и разворачивание секции справочников.
- Модальное окно добавления товара в ассортимент.
- Сортировка, фильтры и пагинация.
- Ручное сохранение или откат изменений.
- Запуск скачивания XLSX.

Структура фронтенда:

- `public/assets/app.jsx` только собирает экран.
- `public/assets/composables/useInventory.js` хранит состояние ассортимента, сохранение и операции со справочниками.
- `public/assets/composables/useProductTable.js` хранит фильтрацию, сортировку и пагинацию.
- `public/assets/components/*` содержит компоненты интерфейса.

## Настройка базы данных

Проект использует SQLite.

Файл базы:

```text
data/inventory.sqlite
```

Он создается автоматически при первом запросе:

```text
GET /api/inventory.php
```

В базе хранятся:

- категории;
- справочник названий товаров;
- строки ассортимента.

Если база пустая, она заполняется начальными данными из:

```text
src/Data/SampleProducts.php
```

SQLite-файл считается локальными runtime-данными и исключен из Git через:

```text
data/.gitignore
```

## Исходное тестовое задание

Тестовое задание было дано для позиции PHP-разработчика в ИндигоСофт Цифровые Технологии.

Нужно было:

- Представить, что разрабатывается отчет для компании NanoGadgets, которая продает высокотехнологичные мелочи.
- Придумать 8-10 типов товаров с полями:
  - артикул;
  - название;
  - категория, 3-4 варианта;
  - цена от 1 000 до 50 000 руб.;
  - складской остаток от 0 до 200;
  - дата поставки изначально в пределах 2025 года.
- Создать Excel-файл:
  - лист `Ассортимент`;
  - полная таблица;
  - фильтр по категориям;
  - условное форматирование:
    - остаток `< 10` - красный;
    - остаток `> 100` - зеленый.
- Передать архив со скриптом и сгенерированным файлом.
